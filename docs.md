# Назначение и принцип работы

Приложение предназначено для сканирования и обработки развёрток сигналов с изображения экрана дефектоскопа.

На вход подаётся изображение в формате PNG, где цветной линией отмечен сигнал. Программа:

1. выделяет пиксели выбранного цвета;
2. восстанавливает одномерный цифровой сигнал;
3. позволяет редактировать сигналы;
4. суммирует выбранные сигналы;
5. рассчитывает и отображает спектр суммы.

## Стек

- Python 3.12
- NumPy
- SciPy
- scikit-image
- Matplotlib
- PyQt5/PyQt6

## Ограничения

1. Допустимый формат входных файлов — PNG.
2. Масштаб по осям на всех изображениях должен совпадать.
3. Для корректной реконструкции сигнал должен быть задан ровным цветом (без артефактов сжатия и градиентов).

# Функциональные требования

## 1. Сигналы (верхняя левая часть)

### 1.1. Список сигналов

Содержит список добавленных сигналов. Каждый новый сигнал — новая строка таблицы.

В каждой строке 5 элементов:

#### 1.1.1. Чекбокс «Выбор»

- Состояние по умолчанию: выключен.
- Используется для выбора сигналов, участвующих в суммировании.

#### 1.1.2. Название сигнала

- Значение по умолчанию: `Сигнал X`, где `X` — порядковый номер.
- Доступно редактирование имени непосредственно в ячейке таблицы.
- Пустое имя автоматически заменяется на `Сигнал X`.

#### 1.1.3. Цвет

- Отображается в виде цветного прямоугольника.
- Цвет по умолчанию:
  - для первых сигналов — фиксированные цвета из палитры;
  - далее — случайный цвет.
- При клике по ячейке цвета открывается палитра для выбора нового цвета сигнала.

#### 1.1.4. Кнопка «Удалить»

Удаляет сигнал из списка.

#### 1.1.5. Кнопка «Копировать»

Создаёт копию сигнала:

- значения сигнала копируются;
- назначается новый цвет по правилам цвета по умолчанию;
- имя формируется как `(<Копия>)`, `(<Копия 2>)` и т.д. при необходимости.

### 1.2. Выделение строки

- Доступен выбор только одной строки одновременно.
- При выборе строки её сигнал автоматически отображается в блоке «Редактирование».
- Отдельной кнопки «Показать» в текущей версии нет.

### 1.3. Блок «Параметры развертки»

Содержит:

#### 1.3.1. Текстовое поле `T/2, сек`

- Допустимые значения: неотрицательные числа.
- Разделитель дробной части — точка.
- При некорректном вводе рамка поля подсвечивается красным.

#### 1.3.2. Поле `Количество отсчетов N`

- Допустимые значения: положительные целые числа.
- При некорректном вводе рамка поля подсвечивается красным.

#### 1.3.3. Управляющая строка

Содержит кнопки «Добавить» и «Показать сумму».

##### Кнопка «Добавить»

- Состояние по умолчанию: неактивна.
- Активируется только если `T/2` и `N` заполнены корректно.

При нажатии выполняется следующий алгоритм:

1. Открывается диалог выбора файла.
2. Выполняются проверки:
   1. Проверка расширения файла (`.png`).
      - Если формат некорректный, показывается сообщение:
        `ошибка: некорректный формат`.
   2. Проверка, что изображение цветное (RGB/RGBA).
   3. Проверка ширины изображения.
      - Если ширина изображения меньше, чем `N`, показывается сообщение:
        `ошибка: слишком узкий файл`.
3. Из изображения извлекается список всех уникальных RGB-цветов.
4. Открывается окно выбора цвета линии сигнала из списка найденных цветов.
5. Выполняется реконструкция 1D-сигнала по выбранному цвету.
6. Выполняется прореживание до `N` отсчётов с шагом `N_image // N`.
7. Открывается окно предпросмотра восстановленного сигнала с осью:
   `np.linspace(-T/2, T/2, N, endpoint=True)`.
8. После подтверждения сигнал сохраняется и добавляется в таблицу.

##### Кнопка «Показать сумму»

- Активна, если список сигналов не пуст и отмечен хотя бы один чекбокс.
- Выполняет поэлементное суммирование отмеченных сигналов.
- Результат отображается в блоке «Сумма».

## 2. Редактирование (верхняя правая часть)

### 2.1. Окно графика сигнала

- По умолчанию пустое.
- При выборе сигнала в таблице отображает его график.
- Ось X строится как:
  `np.linspace(-T/2, T/2, N, endpoint=True)`.
- Цвет графика совпадает с цветом сигнала в таблице.

### 2.2. Управляющая вертикальная панель

Все режимы редактирования взаимоисключающие: при включении одного остальные выключаются.

#### 2.2.1. Кнопка «Обнуление»

- Включает режим выделения интервала по оси X (мышью на графике).
- Выделенный интервал обнуляется (`значения = 0`).
- Каждое действие добавляется в стек отмены.

#### 2.2.2. Кнопка «Уровень 0»

- Показывает вертикальный слайдер справа от графика.
- Слайдер сдвигает весь сигнал по вертикали.
- После отпускания слайдера изменение фиксируется как одно действие для «Отмена».

#### 2.2.3. Кнопка «Cдвиг фазы»

- Показывает поле `Введите сдвиг в сек:`.
- Допустимый диапазон: от `0` до `T/2`.
- При корректном вводе выполняется циклический сдвиг сигнала по времени (`np.roll`).
- Изменения добавляются в стек отмены.

#### 2.2.4. Кнопка «Усиление»

- Показывает поле выбора коэффициента усиления (`QDoubleSpinBox`).
- Диапазон коэффициента: от `-10.0` до `10.0`, шаг `0.1`, значение по умолчанию `1.0`.
- Сигнал умножается на выбранный коэффициент.
- Изменения добавляются в стек отмены.

#### 2.2.5. Кнопка «Отмена»

- По умолчанию неактивна.
- Активируется после первого изменения в любом режиме редактирования.
- Отменяет последнее действие из стека.

#### 2.2.6. Кнопка «Сохранить»

- По умолчанию неактивна.
- Активируется при наличии несохранённых изменений.
- Сохраняет отредактированные значения в выбранный сигнал.

## 3. Сумма (нижняя правая часть)

### 3.1. Окно графика суммы

- По умолчанию пустое.
- После нажатия «Показать сумму» отображает суммарный сигнал.
- Ось X строится как:
  `np.linspace(-T/2, T/2, N, endpoint=True)`.

### 3.2. Кнопка «Показать исходные сигналы»

- Кнопка-переключатель.
- Активна только после расчёта суммы.
- В активном состоянии поверх суммы отображает все отмеченные исходные сигналы их цветами.

### 3.3. Кнопка «Сохранить сумму»

- Активна только после расчёта суммы.
- Сохраняет текущий график блока «Сумма» в файл.
- Поддерживаемые форматы: PNG, JPEG, PDF, SVG.

---

## 4. Спектр (нижняя левая часть)

### 4.1. Кнопка «Рассчитать спектр»

- Активна только после расчёта суммы.
- Выполняет БПФ от суммарного сигнала.
- Используются параметры временной оси, заданные через `T/2` и `N`.
- Рассчитываются и сохраняются:
  - амплитуда;
  - фаза;
  - действительная часть;
  - мнимая часть.

### 4.2. Панель режимов отображения

Кнопки «Амплитуда», «Фаза», «Действительная часть», «Мнимая часть»:

- по умолчанию неактивны;
- активируются после расчёта спектра;
- переключают отображаемую компоненту спектра в окне графика.

### 4.3. Окно графика спектра

Отображает выбранную компоненту спектра по частоте.

### 4.4. Кнопка «Сохранить спектр»

- Активна после расчёта спектра.
- Сохраняет текущий график спектра в файл.
- Поддерживаемые форматы: PNG, JPEG, PDF, SVG.
